# Шаг 3 — Панель команд

![Скриншот](images/step3.png)

Чтобы не искать нужное каждый раз — добавьте часто используемые в **избранное** через **«Настроить избранное»**.

Команды также доступны из палитры: нажмите `Ctrl+Shift+P` (Mac: `Cmd+Shift+P`) и введите **«1C»** — фильтр покажет все команды расширения.
