# Шаг 17 - Проект OneScript

![Скриншот](images/placeholder.svg)

В панели **1С: Пакеты** прямая зависимость из `packagedef` стоит на первом уровне. Пакет, который пришёл вместе с ней, вложен в того, кто его запросил. Зависимость для разработки подписана «для разработки».

У проекта OneScript панель **1С: Метаданные** показывает состав пакета: классы, модули и программы из `packagedef`, задачи из каталога `tasks`. Файл и объявление остаются вместе. Программа это `src/main.os`.
