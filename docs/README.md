# Документация 1C: Platform Tools

> <img src="../resources/brand/cat-hi.png" alt="" width="26" align="left"> Каждый раздел — про одну функцию. Ищите по названию панели.

## Руководства по функциям

- **[Инструменты 1С](tools.md)** — дерево команд vanessa-runner: разделы, избранное, настройки путей, выбор установки OneScript и токен GitHub.
- **[Проекты 1С](projects.md)** — поиск проектов, избранное и теги, быстрое переключение, синхронизация.
- **[Администрирование 1С](admin.md)** — список информационных баз платформы и запуск Предприятия или Конфигуратора; консоль кластера через `rac`: подключения, сеансы, свойства баз.
- **[Артефакты 1С](artifacts.md)** — дерево артефактов проекта и действия сборки/разбора.
- **[Метаданные 1С](metadata.md)** — дерево метаданных, поиск и фильтр по подсистемам, создание и изменение объектов, первый запуск и настройки.
- **[Служебные файлы](service-files.md)** — создание из шаблонов: `.gitignore`, `.gitattributes`, `env.json`, файлы `tools/*`.
- **[Автоматизация](automation.md)** — пайплайны (`.1cpt/pipelines.json`) с визуальным редактором графа шагов и хуки команд (`.1cpt/hooks.json`).
- **[Профили запуска](launch-profiles.md)** — env-профили (`env.json`/`env.<id>.json`), выбор активного профиля в статус-баре, временные параметры.
- **[Автономный сервер](autonomous-server.md)** — публикация файловой ИБ через `ibsrv`: запуск/остановка, выбор публикуемых HTTP/Web/OData-сервисов, открытие в браузере, отладка.
- **[ER-диаграммы](er-diagrams.md)** — конструктор схем связей метаданных и экспорт.
- **[Тестирование](testing.md)** — панель тестирования VS Code: Vanessa, xUnit, YAxUnit, OneScript, 1bdd; сборка тестовых обработок и тестовых расширений.
- **[Список дел](todo.md)** — поиск TODO-комментариев, фильтры и настройки.
- **[Отладка 1С](debug.md)** — настройка, запуск, точки останова (условия, логирование, автоперенос), расширения и внешние обработки, переменные и изменение значений, вычисление выражений, замер производительности.
- **[AI и MCP](ai-mcp.md)** — навыки для агентов, файл-триггер, MCP-сервер.
- **[Docker и ibcmd](docker.md)** — выполнение команд в контейнере, сборка образов, GitHub Codespaces.

Пошаговое знакомство со всеми панелями — walkthrough **Начало работы с 1C: Platform Tools** (Help → Welcome) или каталог [walkthrough](../walkthrough).
