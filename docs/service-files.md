# 1С: Служебные файлы

> <img src="../resources/brand/cat.png" alt="" width="26" align="left"> Существующий файл не перезатирается без вопроса.

Служебные файлы это вспомогательные файлы проекта: настройки запуска, параметры тестов, исключения Git. Расширение создаёт их из готовых шаблонов.

Щелчок по отсутствующей строке создаёт файл. Щелчок по профилю запуска, файлу Vanessa Runner и окружению выбирает их, кнопка в такой строке открывает файл для правки. По остальным строкам щелчок открывает файл. Профиль, хуки и пайплайны открываются своим редактором, остальные файлы текстом.

Пересоздание записывает лежащий файл из того же шаблона, что и создание, текущее содержимое пропадает. Профиль спрашивает секции команд, `packagedef` пересоздаётся инициализацией проекта. Пайплайны целиком не перезаписываются: пересоздание предлагает типовые цепочки, отмеченные вставляются в файл или возвращаются к исходному виду, свои цепочки проекта остаются.

В шапке **Создать базовый набор** создаёт недостающие `.gitignore`, `.gitattributes` и основной профиль целиком, со всеми секциями команд. **Проверить связи** проверяет файлы настроек и каталоги отчётов активного профиля.

## Группы

**Профиль запуска.** Файлы установленного vanessa-runner: `env.json` и `env.<имя>` либо `autumn-properties.json` и `autumn-properties.<имя>`. **Создать профиль…** спрашивает имя и секции команд. Подключение записывается всегда.

**Окружение.** **Осн. настройка окружения** создаёт `.env`. **Создать окружение…** спрашивает имя и создаёт `.env.<имя>`.

**Репозиторий.** `.gitignore`, `.gitattributes`, `packagedef` и каталоги проекта. **Структура проекта** отмечена, когда на месте все каталоги шаблона vanessa-bootstrap: у проекта 1C:EDT без `src` и `tests`, у проекта OneScript каталоги пакета. Щелчок создаёт недостающие и не трогает лежащие файлы. У проекта 1С без исходного кода он спрашивает формат.

**Автоматизация.** Хуки, пайплайны и типовые пайплайны.

**Vanessa Runner.** **Прогон тестов** и **Инициализация данных**. Файл с именем посередине показывается этим именем, например `local`. Щелчок ставит файл в строку **1С: Профиль запуска**. Команда «Инициализировать данные» использует файл инициализации целиком. **Другое имя…** спрашивает имя.

**Vanessa Automation, xUnit, YAxUnit, синтаксический контроль.** **Другое имя…** у Vanessa Automation, xUnit и YAxUnit спрашивает имя.

## Файлы

| --- | --- | --- |
| `.gitignore` | `.gitignore` | да |
| `.gitattributes` | `.gitattributes` | да |
| `packagedef` | `packagedef` | нет |
| **Осн. профиль запуска** | `env.json` или `autumn-properties.json` | да |
| **Осн. настройка окружения** | `.env` | нет |
| **Прогон тестов** | `tools/vrunner.json` | нет |
| **Инициализация данных** | `tools/vrunner.init.json` | нет |
| **Прогон тестов** | `tools/VAParams.json` | нет |
| **Инициализация данных** | `tools/VAParams.init.json` | нет |
| **Прогон тестов** | `tools/xUnitParams.json` | нет |
| **Прогон тестов** | `tools/yaxunit.json` | нет |
| **Исключения** | `tools/syntax-check-excludes.txt` | нет |
| **1cpt: hooks** | `.1cpt/hooks.json` | нет |
| **1cpt: пайплайны** | `.1cpt/pipelines.json` | нет |
