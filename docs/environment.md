# Окружение

> <img src="../resources/brand/cat.png" alt="" width="26" align="left"> Переменные, которые получает каждый запуск проекта.

Настройки окружения выбираются в строке состояния, отдельно от [профиля запуска](launch-profiles.md).

## Файлы

Файлы лежат в корне проекта. Следующий перекрывает предыдущий.

| Файл | Когда действует |
| --- | --- |
| `.env` | всегда |
| `.env.local` | всегда, личный |
| `.env.<имя>` | выбрано окружение `<имя>` |
| `.env.<имя>.local` | выбрано окружение `<имя>`, личный |

Образцы `.env.example`, `.env.sample`, `.env.template` и `.env.dist` окружениями не считаются. Переменная из файла перекрывает одноимённую переменную VS Code. Выбор окружения у каждого проекта свой и в репозиторий не попадает.

Формат dotenv: `ИМЯ=значение`, комментарии `#`, кавычки, многострочные значения, ссылки `${ИМЯ}` и `${ИМЯ:-запасное}`. Имена могут быть на кириллице.

Шаблон `.gitignore` расширения исключает `.env`, `.env.local` и `.env.*.local`. Файлы `.env.<имя>` можно хранить в репозитории.

В интерфейсе видны только имена переменных, без значений.

Базу, пользователя, пароль и версию платформы можно задать здесь же: `VRUNNER_IBCONNECTION`, `VRUNNER_DBUSER`, `VRUNNER_DBPWD`, `VRUNNER_V8VERSION`. Они сильнее [файла профиля](launch-profiles.md) и слабее [временных параметров](launch-profiles.md#временные-параметры).

## Создание

В панели **1С: Служебные файлы**, группа **Окружение**, пункт **Осн. настройка окружения** создаёт `.env`. Новый файл перечисляет закомментированными строками переменные, которые читает код проекта.

**Создать окружение…** в панели **1С: Служебные файлы** и в меню строки состояния **1С: Окружение** спрашивает имя, создаёт `.env.<имя>` и выбирает его. В меню строки состояния также **По умолчанию**, окружения проекта и открытие файла. Без выбранного окружения подпись «По умолчанию», если есть `.env` или `.env.local`, иначе «Нет файла окружения». Если выбранного окружения уже нет в проекте, запуски не начинаются.
