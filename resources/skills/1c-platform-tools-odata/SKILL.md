# OData

Запросы к данным и состав стандартного интерфейса выполняются инструментами расширения. Ручной HTTP и отдельные секреты не нужны. `wait: true` возвращает результат.

| Задача | Command ID | MCP |
|---|---|---|
| Запрос к данным | `1c-platform-tools.odata.query` | `odata_query` |
| Состав интерфейса | `1c-platform-tools.odata.setup` | `odata_setup` |

## odata_query

Адрес — публикация автономного сервера проекта (`server_start`, в составе нужен OData; адрес есть в `env_status`, поле `odata`) либо параметр `url` (корень своей публикации). Учётная запись — `db-user` и `db-pwd` профиля или `settingsFile`. Параметра `ibConnection` нет. Пароль в вызов не передаётся.

- `resource` — набор (`Catalog_Номенклатура`), элемент (`Catalog_Номенклатура(guid'…')`), свойство или `$metadata`;
- `method` — `GET` по умолчанию. `POST` создаёт, `PATCH` меняет переданные поля, `PUT` заменяет элемент целиком, `DELETE` удаляет. Меняющие методы — только по явной просьбе пользователя;
- выборка: `filter`, `select`, `expand`, `orderby`, `top`, `skip`;
- `body` — строка JSON для `POST`, `PATCH` и `PUT`.

Своя публикация из `url` — чужая или продуктивная база: только `GET`, всегда с `select` и `top`. `odata_setup` к ней не применяется.

Ответ содержит код HTTP и тело. Большую выборку сужай `top`, `select`, `filter`.

## odata_setup

Состав хранится в базе профиля.

- без `include` и `exclude` возвращает текущий состав именами наборов;
- `include` и `exclude` точечно меняют состав, остальное не трогают. Имя — полное (`Справочник.Номенклатура`) или набор (`Catalog_Номенклатура`);
- `available: true` добавляет объекты проекта вне состава. У большой конфигурации список может быть неполным.

Изменение состава запускает служебную обработку в Предприятии и на это время останавливает автономный сервер этой базы. Нужны административные права.

## Примеры

- Десять товаров: `odata_query` с `resource: "Catalog_Номенклатура"`, `top: 10`, `select: "Ref_Key,Description"`.
- Объект не в составе: `odata_setup` с `include: ["Catalog_Номенклатура"]`, затем повтори запрос.
