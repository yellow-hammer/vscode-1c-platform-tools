# Версия конфигурации, расширения и внешних файлов

Эти команды спрашивают версию в окне VS Code. Агентный вызов отклоняется: «Команда открывает окна VS Code и недоступна агенту. Версия запрашивается в окне VS Code; выполняется пользователем.» Инструмента MCP нет, имя из command id не собирай и команду через канал агента не вызывай. Попроси человека выполнить её в палитре.

| Задача | Command ID |
|---|---|
| Версия конфигурации | `1c-platform-tools.cf.setVersion` |
| Версия расширения | `1c-platform-tools.cfe.setVersion` |
| Версия внешней обработки | `1c-platform-tools.epf.setVersionProcessor` |
| Версия внешнего отчёта | `1c-platform-tools.epf.setVersionReport` |

Обработке и отчёту команда из палитры может получить имя объекта. Агенту передать версию некуда: номер всё равно спрашивается у человека.
